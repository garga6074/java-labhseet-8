# Expected Output Guide

Actual host information and current date depend on the computer running the program.

| Program | What to verify |
|---|---|
| BeanExercisesDemo | Displays bean properties, calculated values, serialized employee, property-change events and introspection |
| InetAddressDemo | Prints host name and resolved IP address |
| HelloServer + HelloClient | Server prints `Client connected` and `Received from client: Hello Server` |
| EchoServer + EchoClient | Server echoes the line entered by the client |
| MessageReceiver + MessageSender | UDP receiver prints `Ping` |
| WebReader | Prints HTTP status and response body if the URL is reachable |
| FileDownloader | Downloads a file if the specified path exists |
| MultiClientServer + MultiClientClient | Prints each message with a worker thread name |

Rectangle example: length 10 and width 5 gives area 50 and perimeter 30.
Circle example: radius 7 gives area approximately 153.94 and circumference approximately 43.98.

Network programs may be affected by firewalls, proxy settings, unavailable ports, DNS and internet connectivity.
